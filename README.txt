# AJHC website starter — refined version

This is a local custom-coded homepage prototype for the African Jewish Heritage Centre.

## Open the preview
Keep all files and folders together. Open `index.html` in Chrome or another browser.

## Contents
- `index.html` — homepage content and structure
- `styles.css` — responsive design and refined sizing
- `script.js` — mobile navigation
- `assets/ajhc-logo.png` — supplied AJHC logo
- `assets/elephant-hero.mp4` — converted elephant footage
- `assets/hero-poster.jpg` — still frame fallback

## Latest design refinements
- Larger AJHC logo in the desktop and mobile header.
- Larger editorial headings while retaining the existing Playfair Display font.
- Tighter, more balanced welcome section with reduced unused vertical space.
- Slightly larger and more readable introductory body copy.

## Important
This is a local preview, not a live website. The newsletter, map, journal content, contact form, store checkout and private CMS still need to be connected and implemented. The newsletter link is currently an email link placeholder. The elephant video is the supplied Pixabay footage; retain its listing and licence record.

Do not change the Squarespace DNS records until hosting and email have been tested.
